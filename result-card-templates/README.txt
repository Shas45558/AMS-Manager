Amtoli Model School Result Card Template

The original Word template is kept here for reference. The Android result-card export now uses the converted HTML layout at:
app/src/main/assets/amtoli_result_card_template.html

Result-card content is filled locally from student records and marks. The app opens Android's native print preview, where the user can choose Save as PDF. No conversion API or server is used. The school logo is bundled in app/src/main/assets/amtoli_school_logo.png.

The layout is recreated from the supplied DOCX structure; it is not a Word-engine rendering and may differ slightly from Microsoft Word pagination.
