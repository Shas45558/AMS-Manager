App feature:
Reports > Student report cards creates one combined PDF for the selected class/section and exam. Every selected student gets an individual page. The PDF is generated on-device using Android's PDF APIs, so no internet-based DOCX conversion service is needed. The generated result-card layout follows the supplied DOCX fields and subject list; it is a native PDF rendering, not a DOCX file with editable Word fields filled in.

Important:
- Result cards use marks currently saved on the device; sync first if you need the latest shared records.
- Student name, father's name, class, section, roll, address, subject marks, total, GPA, and grade are filled where data exists.
- Behavior, working-day/attendance details, monthly evaluation average, exam date, comments, and signatures remain blank because this export path does not currently have all of those values available.
- The Gradle wrapper JAR is absent from this source package, so a successful build could not be verified in this environment. Run `gradle wrapper` in a configured Gradle environment before using `./gradlew`.
